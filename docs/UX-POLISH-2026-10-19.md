# Desk UX polish — 2026-10-19

Artem requested alignment, organization and UX improvements, and reported a missing icon while the
window was open. This work is separate from the paused release-validation goal.

## Changes

- Shared amber bolt artwork for the tray, Desk title bar, taskbar and application header. The Windows
  MSVC executable embeds 16–256 px icons; the installed shortcut explicitly selects that icon. The
  running Desk sets the same app identity as its shortcut.
- A consistent light/dark palette, readable secondary text, 14 px body text, 22 px page headings,
  32 px controls, and shared margins and spacing.
- Brand/connection status and navigation have separate rows. Inbox cards have a clear selected state,
  wrapping titles, and accessible question/batch labels. Paging controls appear only when needed.
- Question details distinguish the answer area from source information. Immediate-send choices are
  explained, forms fit narrow panes, and text/form submission has a clear primary button.
- Agents and Owners use readable cards instead of wide tables. Settings has separate Notifications,
  Phone replies and Owners sections with independent scroll positions. Phone fields align and setup
  guidance is expandable.
- Consistent page headings, improved empty/offline states, Enter-to-search in directories and History,
  and a clear search-reset action for agent/owner directories.

## Inbox refinement

Artem found the Desk cluttered and said past chats looked like active questions requiring a reply.
Past questions now start collapsed, including when the Inbox is empty and when returning to the Inbox.
Their disclosure has a stable identity, so a changing result count does not unexpectedly expand it.
Persisted expansion from an earlier app run is reset on first display.

Active and past selections are separate. Opening or refreshing the Desk selects only a waiting
question; a past question needs an explicit click. Collapsing the past section clears its detail view.
When nothing is waiting, the detail pane says “You’re all caught up.” Past questions show their outcome
and “No reply needed”; priority, urgency and overdue-deadline cues are reserved for active questions.
Defaulted, withdrawn and not-needed outcomes retain their distinct meanings.

Active cards lead with the question title. Routine P2 badges are omitted, while P0/P1 remain visible.
Batch checkboxes appear only after “Select several”; cancelling selection leaves unsent drafts intact.
Restored batch selections remain available after an upgrade.

The default window height is now 620 px so a fresh window fits a 720 px display; existing saved window
sizes are retained. The Desk release build completed successfully. In the isolated `ux-calm-1019`
preview, an empty Inbox showed the caught-up state with past questions collapsed. Expanding that
section did not select a question. An explicitly opened past question showed “Answered · No reply
needed” without urgency cues, and collapsing it returned to the active question. Active cards showed
no batch checkboxes until selection mode was enabled. No automated suites or release checks ran.
